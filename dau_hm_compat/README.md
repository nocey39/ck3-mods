# 自动建设助手 × 幻萌入侵 兼容补丁

适用版本为 CK3 1.21.0.3（Florin）、自动建设助手 0.10.5、幻萌入侵角色包 2.1。

## 加载顺序

1. 启用自动建设助手和幻萌入侵角色包，以及角色包要求的二向箔核心库和婚舰通用库。
2. 将本补丁放在自动建设助手和幻萌入侵角色包之后。

本补丁与庄园建筑师及其他覆盖原版庄园建筑定义的补丁存在同文件冲突。

## 秘密基地建设

- 住所自动建设设置里勾选“手动选择”时，可通过事件选择合资格的新建筑。取消勾选后，助手直接在可用空槽开工。
- 已有建筑按助手的升级规则处理。建造和升级都沿用现有储备设置、原版造价和建造条件。
- 63 个庄园建筑及升级等级无需庄园主楼，仍须满足各自的建造条件。118 个要求庄园主楼的建筑等级继续受原版门槛限制。
